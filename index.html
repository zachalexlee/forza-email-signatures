Install your signature

Gmail
  1. Click Copy signature above.
  2. In Gmail, open ⚙ Settings → See all settings → General.
  3. Under Signature, click Create new, name it, and paste (Ctrl/Cmd+V) into the box.
  4. Set it as the default for new emails and replies, then Save Changes at the bottom.
Outlook (new Outlook & web)
  1. Click Copy signature above.
  2. Go to Settings → Account → Signatures.
  3. Create a new signature, paste into the editor, and select it under default signatures.
  4. Click Save.
Outlook (classic desktop)
  1. Click Copy signature above.
  2. Open File → Options → Mail → Signatures…
  3. Click New, name it, paste into the edit box, and choose it for new messages and replies.
  4. Click OK.
Apple Mail (Mac)
  1. Click Copy signature above.
  2. Open Mail → Settings → Signatures, pick your account, and click +.
  3. Uncheck Always match my default message font, then paste into the signature area.
  4. Drag the signature onto your account and select it in the composer.
iPhone / iPad
  1. Email yourself a message containing the signature (or open this page on your phone and copy).
  2. Select and copy the signature from the received email.
  3. Open Settings → Mail → Signature and paste. If formatting drops, shake the device and tap Undo to restore rich formatting.
